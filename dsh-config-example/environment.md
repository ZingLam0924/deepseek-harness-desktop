## 说明

- 上面的运行时版本是这套配置**当前实测**的版本；其中 Node / npm / pnpm 是 MCP 挂载与前端构建所依赖的，
  Python 供 `scrapling` 用，JDK / Maven 供 Java 后端项目用。
- 版本不必逐字一致，但建议 Node ≥ 20、Python ≥ 3.11，其余按各自项目要求。
